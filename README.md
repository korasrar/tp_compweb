# PokeMafia | Foucher Mattéo et Maubert Céléstin

## Installation & Lancement

### 1. Lancer l'API des notes
   ```bash
   cd PokeMafia/js/data
   npx json-server notes.js
   ```
### 2. Lancer le client
    ```bash
    cd PokeMafia/
    php -S localhost:8000
    ```
puis ouvrez ce lien http://localhost:8000/#/list/0
